# Security Policy

## Reporting A Vulnerability

Please report security issues privately before opening a public issue. If the repository owner has enabled GitHub private vulnerability reporting, use that channel. Otherwise, contact the maintainer through the profile or project contact listed on GitHub.

Please include:

- A concise description of the issue
- Steps to reproduce
- Affected macOS and V-Paste versions
- Any relevant logs, crash reports, or proof-of-concept details

## Sensitive Clipboard Data

V-Paste stores clipboard history locally. Security reports involving unintended retention, exposure of stored clipboard data, unsafe link preview fetching, or insecure release artifacts are in scope.
